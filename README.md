# SENAI CQPG106282 - Programador WEB: PROJETO FINAL PROGRAMADOR WEB

Este repositório contém os códigos básicos de uma página HTML apenas para simulação da hospedagem e publicação de um site

O objetivo do curso é a formação de um programado web Full-Stack Junior, iniciando com o tratamento de imagens
passando pela lógica de programação, conhecimentos de HTML5 e CSS3, introdução ao JavaScript e PHP.
